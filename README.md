# 🌍 Wanderlust — Travel Explorer Website

> **Discover places. Create memories.**

A modern, responsive Travel Explorer Website built with pure HTML, CSS, and JavaScript — created for a college **User Interface Design** activity.

## 🔗 Live Demo
**[View Website →](https://Avadhut1602.github.io/wanderlust/)**

---

## 📸 Sections
- **Hero** — Full-screen travel photography with CTA
- **Popular Destinations** — Bali · Manali · Paris · Goa (with detail modals)
- **Features Strip** — What makes Wanderlust special
- **About** — Our story and stats
- **Contact** — Form with validation (demo)
- **Footer** — Links, tagline, copyright

## ✨ Features
- ✅ Sticky navbar (transparent → frosted glass on scroll)
- ✅ Mobile hamburger menu with slide-in drawer
- ✅ Destination detail modals with highlights & price
- ✅ Contact form with inline validation & success state
- ✅ Scroll-triggered card fade-in animations
- ✅ Back-to-top button
- ✅ Image fallbacks for reliability
- ✅ Fully responsive (mobile · tablet · desktop)
- ✅ Accessibility: ARIA labels, focus-visible, reduced-motion support

## 🛠 Tech Stack
- **HTML5** — Semantic structure
- **CSS3** — Custom properties, Flexbox, Grid, animations
- **Vanilla JavaScript** — Zero dependencies
- **Google Fonts** — Poppins
- **Unsplash** — Travel photography

## 🚀 Run Locally
Just open `index.html` in any browser — no build step or server required.

```bash
git clone https://github.com/Avadhut1602/wanderlust.git
cd wanderlust
# open index.html in your browser
```
